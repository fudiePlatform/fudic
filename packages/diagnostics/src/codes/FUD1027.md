# FUD1027 — A multilingual build without a site
**error** · SDD-58

Every page of an app in two or more languages carries a `canonical` link and one `hreflang` link per language, and search engines only accept them as absolute URLs. A page written at build time has no request to take the origin from, so the build needs it from `fudic.json`. `pnpm dev` does not: it uses the origin of each request.
**Fix:** add `"site": "https://example.com"` to `fudic.json`, the origin the app is published at.
