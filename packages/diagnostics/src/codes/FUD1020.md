# FUD1020 — `t()` that cannot be extracted
**error** · SDD-58

A message is extracted and compiled per locale, so `t()` needs a string literal as its first argument. When the message has holes (`{name}`), the second argument must be an object literal with one key per hole.
**Fix:** `t("Hello {name}", { name: user.name })` — never `t(text)` nor `t("Hello {name}")` alone.
