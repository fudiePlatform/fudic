# FUD0055 — No parser injected for a construct
**error** · SDD-05

The HTML parser met a `@` construct (a control keyword or `@code`) but was built without the parser that handles it. It is a wiring bug in whoever invoked the HTML parser, not a mistake in your source.
**Fix:** report it with the `.fud` that triggers it; tooling that calls the parser directly must inject the construct parsers.
