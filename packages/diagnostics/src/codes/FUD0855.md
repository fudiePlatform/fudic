# FUD0855 — `@import` in a component `<style>`
**error** · SDD-49

A component's `<style>` becomes an adopted stylesheet, and the browser silently ignores `@import` in an adopted sheet, so the imported rules would never apply.
**Fix:** remove the `@import` and choose the sheet by name: declare it under `styles` in `fudic.json` and list it in `shadowrootadoptedstylesheets`.
