# FUD0199 — Slot that fills nothing
**error** · BUG-23

A `slot="x"` (or the `slot:` of a layout hole) is projected into its PARENT's shadow, so the parent has to be a component that declares `<slot name="x">`. Here there is no component parent, or it declares no such slot.
**Fix:** correct the slot name, declare `<slot name="x">` in the parent component, or remove the attribute.
