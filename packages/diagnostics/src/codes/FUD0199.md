# FUD0199 — Slot that fills nothing
**retired** · BUG-23

It was raised for a `slot="x"` whose parent is not a component that declares `<slot name="x">`. Since SDD-35 the build typechecks every `.fud`, and the projection makes TypeScript report the same slot against the parent's declared slots.
**Replaced by:** the TypeScript error the projection raises on the `slot` value, in the editor and in the build.
