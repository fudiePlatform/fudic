# FUD1090 — Route declaration outside a route
**error** · SDD-60

`load`, `paths` and `layout` belong to a page: the `ctx.params` they receive come from the route of the `.fud` the file sits next to (`src/routes/blog/[slug].fudapi` beside `[slug].fud`). This file is not the sibling of a route.
**Fix:** move the declaration to the `.fudapi` next to the route's `.fud`.
