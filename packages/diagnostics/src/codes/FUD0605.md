# FUD0605 — Bad `shadowrootreferencetarget`
**error** · BUG-42

The reference target bridges a label outside the component to an element inside it, and the compiler has to see that element to back the bridge. The value is dynamic, or names an `id` no element of the root template has.
**Fix:** write the static `id` of an element of the template: `<template shadowrootmode="open" shadowrootreferencetarget="field">` … `<input id="field">`.
