# FUD1508 — The page did not settle
**error**

Before each `then` the workbench waits for the page to be still: no request in flight, no timer due within a second, no animation frame pending. A `then` checked before that could pass on a half-loaded page. This page kept busy past the time limit, and the message lists what was still pending.
**Fix:** find what keeps the page busy — a request that never ends, a timer that rearms itself — or answer it from the fixture.
