# FUD1508 — The page did not settle
**error**

Before each `then` the workbench waits for the page to be still: no request in flight, no timer due within a second, no animation frame pending. A `then` checked before that could pass on a half-loaded page. The page gets 5 s from the last request that finished, so a slow but moving page (a cold dev server sending modules) is waited for, up to 30 s in all. This page went 5 s with nothing finishing, or was still busy at 30 s, and the message lists what was still pending.
**Fix:** find what keeps the page busy — a request that never ends, a timer that rearms itself — or answer it from the fixture.
