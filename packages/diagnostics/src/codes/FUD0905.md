# FUD0905 — Code defined in the view
**error** · SDD-61

A function, class, method, tagged template or arrow defines code where only values belong, even an arrow with an expression body. The one exception is the arrow passed to `filter`, `map`, `reduce` or `toSorted`, which FUD1145 checks.
**Fix:** declare the function in `@code` for a handler, or write the value with the collection operations.
