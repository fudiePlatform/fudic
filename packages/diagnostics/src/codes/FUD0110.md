# FUD0110 — Missing `{` after `@code`
**error** · SDD-08

`@code` is a block of JavaScript, and it must open its body with `{`. (A `@server` / `@client` without one is `FUD1110`, like any other: SDD-60 retired the regions.)
**Fix:** open the body right after the keyword: `@code { const n = signal(0); }`.
