# FUD0110 — Missing `{` after `@code`
**error**

`@code` is a block of JavaScript, and it must open its body with `{`. (A `@server` / `@client` without one is `FUD1110`, like any other: a `@code` has no regions any more.)
**Fix:** open the body right after the keyword: `@code { const n = signal(0); }`.
