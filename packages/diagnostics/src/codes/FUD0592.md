# FUD0592 — `control` on an unsupported element
**error**

`control` binds an element's user value to a form node. `submit`, `reset`, `button` and `image` inputs have no value to read or write. `<input type="file">` binds: to a `file`, or with `multiple` to a `file[]`.
**Fix:** move the `control` to an element that holds a value, or handle the button with an `@click`.
