# FUD0592 — `control` on an unsupported element
**error** · SDD-34

`control` binds an element's user value to a form node. `submit`, `reset`, `button` and `image` inputs have no value, and `<input type="file">` is out of scope in v1 (it needs multipart and a non-JSON value).
**Fix:** move the `control` to an element that holds a value, or handle the button with an `@click`.
