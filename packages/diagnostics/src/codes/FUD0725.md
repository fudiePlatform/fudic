# FUD0725 — `fudic.json` is malformed
**error**

`fudic.json` could not be read, is not a JSON object, or one of its fields has the wrong shape — or a CLI flag would write such a value into it. A project's identity is read as a unit, so a broken file means no configuration at all.
**Fix:** correct the field the message names: `"id": "shop"` (lowercase, may contain hyphens) or `"kind": "app"`; `"locales"` is a non-empty array of distinct BCP 47 tags, e.g. `["es", "en"]`; `"site"` is the origin the app is published at, e.g. `"https://example.com"`, with no path, query or fragment; `"server"`, `"browser"` (and `"api"` in a library) are folders relative to the project and inside it, e.g. `"src/backend"`; `"earlyHints"` is `true` or `false`, and `"css"` is `"inline"` or `"link"`.
