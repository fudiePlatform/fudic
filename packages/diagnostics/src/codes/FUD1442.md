# FUD1442 — A piece name that cannot be adopted
**error**

Every file the guide imports that a component could adopt is a piece, named after its file: `button.css` is `button`. This file's name is not a valid sheet name (a hyphen, an upper-case letter), so no `shadowrootadoptedstylesheets` could ever name it.
**Fix:** rename the file, e.g. `my-button.css` to `mybutton.css`, and its `@import`.
