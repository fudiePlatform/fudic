# FUD0461 — Identifier starting with `$`
**error** · SDD-24

Identifiers whose name starts with `$` belong to the code the compiler generates around yours; one in `@server` or `@client` could collide with it. Only the prefix is reserved: `foo$` and `obj.$bar` are fine.
**Fix:** rename it without the leading `$`: `const $count = 0` → `const count = 0`.
