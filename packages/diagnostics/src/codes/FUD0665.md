# FUD0665 — Non-bubbling event delegated
**error** · SDD-37

A delegated handler listens on an ancestor and waits for the event to bubble up from the row; this event never bubbles, so it would never arrive.
**Fix:** use its bubbling counterpart when the message names one (`@mouseover` for `@mouseenter`), or bind the event on the row itself without `$name`.
