# FUD1161 — A JSX expression as an attribute value
**error**

A value in braces is how JSX passes an expression. fudic's markup is HTML with `@`: braces are not an expression there, and an unquoted value is not HTML either.
**Fix:** bind with `@`: `.value=@x` for a property, `title="@x"` for an attribute, `@click=@save` for an event.
