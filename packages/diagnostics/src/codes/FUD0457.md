# FUD0457 — Unusable service or form name
**error** · BUG-50

The name of `fudic g service` and `fudic g form` becomes a file name and a TypeScript identifier (`shopping-cart` → `shopping-cart.service.ts` and `ShoppingCart`), so it must be kebab-case and start with a letter. Nothing is written.
**Fix:** write it in kebab-case, e.g. `fudic g service shopping-cart`.
