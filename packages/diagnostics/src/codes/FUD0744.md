# FUD0744 — Unknown adopted stylesheet
**error** · SDD-46

A component chooses its sheets by name in `shadowrootadoptedstylesheets`, and those names come from the `styles` of its project's `fudic.json`. This name is not one of them, so there is no sheet to adopt.
**Fix:** use a name declared under `styles`, or declare the sheet there: `"styles": { "cards": "./src/cards.css" }`.
