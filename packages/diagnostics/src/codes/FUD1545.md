# FUD1545 — The page policy blocks what fudic emits
**error**

The build wrote something into the pages (an inline script, a style, a script that loads behind `'strict-dynamic'`, the Trusted Types policy) and the `Content-Security-Policy` of `page.headers` does not let it in. The page would load broken.
**Fix:** add the source the message names to that directive (the bulb does it), or stop using what needs it.
