# FUD1522 — A silenced line needs a code and a reason
**error**

A `fud-disable` or `fud-disable-next-line` comment names the codes it silences and says why, so the next reader knows the warning was seen and kept on purpose. Without both, or written another way, it silences nothing.
**Fix:** write it whole: `fud-disable-next-line FUD1380, FUD1022: why it is fine here`.
