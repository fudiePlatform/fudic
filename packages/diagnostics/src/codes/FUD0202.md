# FUD0202 — Callback passed to a component that does not hydrate
**error**

A function crosses by reference into a component that never comes alive in the browser: nothing in it binds or calls the callback, so it has no client chunk and the function is never called. (A signal never gets here: the component that hands one over makes its child hydrate.)
**Fix:** use the callback in the child, e.g. `<button @click=@onSave()>Save</button>`, which makes it hydrate, or stop passing it.
