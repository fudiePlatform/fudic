# FUD1583 — The runtime is the layout's
**error**

A route wrote `<script type="module" src="fudic:runtime">` in its `<head>`. The layout owns the document, and its marker is where fudic writes the scripts of every page that links it: one in a route goes nowhere.
**Fix:** delete it from the route and keep it in the `<head>` of the layout.
