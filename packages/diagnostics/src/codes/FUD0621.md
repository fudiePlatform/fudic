# FUD0621 — Route reads `data` with no `load`
**warning**

The `@code` of this route reads `data`, but no `.fudapi` it links declares `load`, so nothing ever fills it and `data` is always `undefined`.
**Fix:** link a `.fudapi` that declares `load` (`<link rel="server" href="./index.fudapi">` with `load ssr` and its fields), or stop reading `data`.
