# FUD0666 — `$name` outside an event binding's arguments
**error** · SDD-37

A `$`-prefixed name belongs to the compiler, and a delegated row only exists while an event is being dispatched, as an argument of the handler; anywhere else there is no row to read it from.
**Fix:** read the row in an ancestor's handler, by its name: `@click="@pick(item)"`.
