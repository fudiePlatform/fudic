# FUD0908 — Statement not allowed in `@{ }`
**error** · SDD-61

An `@{ }` block holds `const` and `let`, with object patterns, and reassignments of a variable (`x = e`, `x += e`, `x++`). Conditionals, `switch`, loops, nested blocks and calls are written with `@if`, `@switch`, `@foreach` and friends, or belong in `@code`.
**Fix:** use the markup's own control flow, or compute the value in `@code`.
