# FUD0800 — Library written for another compiler
**error** · SDD-45

A library publishes `.fud` source, so the consumer's compiler parses it. Its `peerDependencies` range on `@fudic/compiler` excludes the version this build resolved, and a mismatch shows up as a syntax error in a file you did not write. Supersedes `FUD0762`.
**Fix:** upgrade the library or the framework so the version falls in the range, or ask the library to widen it.
