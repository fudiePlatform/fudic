# FUD1380 — Event binding inside a loop
**warning**

An `@event` on an element inside a `@foreach`, `@for` or `@while` adds one listener per item, so a long list pays for each row. It still works; the warning does not stop the build.
**Fix:** put the handler on an element outside the loop, pass it the row (`@click=@remove(p)`), and mark the row with `delegate:p="click"`.
