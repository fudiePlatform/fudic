# FUD0161 — Inline body in a code `<script>`
**error** · SDD-10

fudic does not support inline script: the body of a `<script>` that runs code is not emitted, so it would be dropped silently. Data blocks (`application/ld+json`, `importmap`) are the exception and stay inline.
**Fix:** move the code to a file and reference it: `<script type="module" src="/app.js"></script>`.
