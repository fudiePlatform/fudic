# FUD0990 — `@raw` is not the only content of its element
**error** · SDD-54

`@raw(…)` writes markup whose number of nodes is unknown until it runs, so it owns the whole content of one element: hydration adopts that element and never walks inside it.
It cannot share the element with text, other elements or another `@raw`, and it cannot sit directly in a shadow root or in the body of a construct.
**Fix:** wrap it: `<div class="post">@raw(html)</div>`.
