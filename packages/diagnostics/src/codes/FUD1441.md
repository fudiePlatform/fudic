# FUD1441 — An adopted piece styles nothing here
**warning**

The component adopts a piece of the style guide, and none of its rules can match anything its template writes. Nothing is ever removed for you: a script may create the elements at run time, and only the author knows.
**Fix:** remove the name from `shadowrootadoptedstylesheets`, or keep it if a script needs it. The quick fix removes it; "fix all" never does.
