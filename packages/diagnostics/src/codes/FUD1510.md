# FUD1510 — A fixture value the editor cannot read
**error**

The editor reads a fixture without running it: the names of `data`, `calls` and `services`, and the values of `paths`. A spread, a computed key, or a group built by a call hides them, so the lines that name them cannot be checked or completed.
**Fix:** write the group as an object literal with plain keys, and `paths` as an array of strings.
