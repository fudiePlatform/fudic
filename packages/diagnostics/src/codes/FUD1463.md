# FUD1463 — `$value` on an input with a dynamic `type`
**error**

The type of `$value` comes from the `type` of the `<input>`: a checkbox gives `boolean`, a number `number | null`, a text `string`. With `type=@expr` it could be any of them.
**Fix:** write the `type` as a literal, or pass `$event` and read the value yourself.
