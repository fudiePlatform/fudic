# FUD0950 — Unknown fixture
**error**

A fixture line names an entry of the `.fixture.ts` beside the spec: `props` a key of a component's fixture; `data`, `answers` and `services` a key of the group of that name in a page's or a flow's. The message lists the names the file has.
**Fix:** use one of the listed names, or add the entry to the fixture file.
