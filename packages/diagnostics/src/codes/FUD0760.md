# FUD0760 — Link to a package that does not resolve
**error** · SDD-43

A `<link rel="component" href>` names a package specifier that does not resolve: either the package is not installed, or it is installed and its `exports` do not publish that file. They are two different fixes, and the message says which one applies.
**Fix:** install the package (`pnpm add <pkg>`), or ask the package to export the file in its `package.json`.
