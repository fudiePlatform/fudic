# FUD0595 — `control` outside its form
**error** · SDD-34

A form node binds inside its own form, so every `control` needs a `<form control="@f">` above it in the same template. A component that binds a node handed to it by its parent marks its root template `formassociated` instead.
**Fix:** wrap the field in `<form control="@f">…</form>`, or add `formassociated` to the component's root template.
