# FUD0455 — Nothing to add by that name
**error** · BUG-50

`fudic add` adds an optional module of fudic — `di`, `forms`, `http`, `i18n` — or a library of the workspace, and the name given is neither. Nothing is changed.
**Fix:** use one of the names the message lists; a library that does not exist yet is `fudic g lib <name>` first.
