# FUD1481 — A file cannot be page data
**error**

What `load`, `layout` and `paths` return is rendered into the page and sent to the Service Worker as data; a file's bytes do not belong there. When the type is declared elsewhere, the diagnostic points at the use and its related location at the field.
**Fix:** return what identifies the file (an id) and serve it from a `get … -> file`, linked with `url()` in an `<img src>` or `<a href>`.
