# FUD0891 — Text in a slotted hole
**error** · SDD-48

The layout puts this hole in a named slot, and `slot="x"` is an attribute only an element can carry: loose text there would fall into the component's default slot. This is the SDD-48 rule that was numbered `FUD0441` before.
**Fix:** wrap the text in an element: `<p>Hello</p>` instead of `Hello`.
