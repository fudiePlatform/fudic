# FUD0820 — Missing or invalid snippet name
**error** · SDD-29

A snippet name is `[A-Za-z_][A-Za-z0-9_]*`: it becomes a TypeScript function name, and a hyphen would read as a subtraction in a `@render` header.
**Fix:** `@snippet product_card(…) { … }` / `@render product_card(…)`, not `product-card`.
