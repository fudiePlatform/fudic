# FUD1160 — A React prop name as an HTML attribute
**error**

`className` and `htmlFor` are the names React gives to `class` and `for`. In fudic the markup is HTML, so the browser reads them as unknown attributes and the class or the label never applies.
**Fix:** write the HTML name: `class="card"`, `for="email"`; a class that changes is `class:active=@on`.
