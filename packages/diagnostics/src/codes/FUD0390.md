# FUD0390 — `sw.json` is malformed
**error** · SDD-20

`sw.json` does not parse as JSON, has no `shell` array, or declares a resource rule without a `pattern` or with an unknown `policy`.
**Fix:** correct the file, e.g. `{ "shell": ["/"], "resources": { "api": { "pattern": "/api/", "policy": "network-first" } } }`.
