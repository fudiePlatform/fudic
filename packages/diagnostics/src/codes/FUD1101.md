# FUD1101 — Argument that does not fit in a URL
**error** · SDD-60

Route and `query` arguments travel in the URL, one value each: `str`, `bool`, a number, `date`, `uuid` or an `enum`. A route argument is a segment, so it cannot be `?`; a query argument can.
**Fix:** move the argument to the body, or give it a scalar type.
