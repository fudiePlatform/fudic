# FUD1101 — Argument that does not fit in a URL
**error**

Route and `query` arguments, and every argument of a `get`, travel in the URL, one value each: `str`, `bool`, a number, `date`, `uuid` or an `enum`. A route argument is a segment, so it cannot be `?`; a query argument can.
**Fix:** give it a scalar type, or move it to the body of a verb that has one (`post`, `put`).
