# FUD0191 — Undeclared component
**error**

A hyphenated tag is a custom element, and every custom element a file uses has to be declared so the compiler knows which component it is.
**Fix:** in a component or a route, put it at the top of the file (a route: after its `<link rel="layout">`); in a page or a layout, inside `<head>`: `<link rel="component" href="./app-card.fud">`.
