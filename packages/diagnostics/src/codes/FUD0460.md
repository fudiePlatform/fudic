# FUD0460 — Link `href` resolves to no file
**error** · SDD-24

The `href` of a `<link rel="component">` or `<link rel="layout">` does not point at an existing `.fud` file, so the tag or layout it declares cannot be read.
**Fix:** correct the path, or create the file (the editor offers to): `<link rel="component" href="./card.fud">`.
