# FUD1540 — A line that is not a header
**error**

A line of a `.headers` file is not `Name: value`, an indented continuation or a `#` comment; or it continues a header whose values cannot be split over lines; or it is a header of `assets.headers` with no path above it; or it is a path in `page.headers` or `sw.headers`.
**Fix:** write `Name: value` at column 0, put the value of that header on one line, open a block with a path (`/**` for every file), or remove the path.
