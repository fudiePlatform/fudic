# FUD0787 — the component cannot be linked from another package
**error** · SDD-44

`fudic g component --project <lib> --in <file of another package>` links the new component by its package name, and the library's `exports` do not list the folder it is generated into, so from outside the library it has no name.
**Fix:** generate it under a folder the library's `exports` lists (`src/components` by default), or add one to `exports`.
