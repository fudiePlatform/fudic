# FUD0726 — `id` required by a Service Worker
**error** · SDD-41

The project emits a Service Worker (it has a `sw.json`), and its caches are named after the project `id`. Without one, two applications on the same origin would wipe each other's caches. Was `FUD0721`.
**Fix:** declare an id in `fudic.json`: `{ "id": "shop" }`.
