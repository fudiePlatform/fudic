# FUD1021 — Translation in an app without locales
**retired** · SDD-58

It was emitted for a pipe, `t()`, `format()` or `locale` in an app whose `fudic.json` declared no `"locales"`. Since SDD-71 every app has a language: without `"locales"` it is `en`, so the case no longer exists.
**Replaced by:** nothing — the default locale.
