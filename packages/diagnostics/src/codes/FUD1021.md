# FUD1021 — Translation in an app without locales
**error** · SDD-58

Pipes, `t()`, `format()` and `locale` are compiled with the locale of the page, and an app without `"locales"` in its `fudic.json` has none to give them.
**Fix:** declare the languages, e.g. `"locales": ["es"]` — the first one is the language the code is written in.
