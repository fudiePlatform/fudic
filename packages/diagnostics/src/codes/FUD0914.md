# FUD0914 — Snippet that renders itself with nothing in between
**retired**

It reported a snippet whose body rendered itself with no `@if`, `@switch` or loop between. A snippet is expanded when the file compiles, so any snippet that renders itself never finishes expanding, with a condition around the call or without one: the case was always `FUD0835` as well. The number is not reused.
**Replaced by:** `FUD0835`, which reports every snippet that renders itself, directly or through others; a recursive structure is a component.
