# FUD1000 — Chain that cannot be read at compile time
**error** · SDD-56

The client has to know which `.client` halves to import without running the `@server`, so the chain of a server function and of `export const http` is read by the compiler.
It reads identifiers in `.use` and `.skip`, string literals in `.invalidates`, `false` or an object literal in `.compress`, and a verb called directly or through a `const` of the same `@server`; anything computed is out of its reach.
**Fix:** `export const save = put().use(auth).invalidates('/blog').handle(…)`.
