# FUD1002 — `load` with a verb other than `get()`
**error** · SDD-56

`load` is the page's own data: the browser asks for it when it navigates and the Service Worker when it fetches the data endpoint, and both ask with a GET.
Another verb would declare a request nobody makes.
**Fix:** `export const load = get().use(auth).handle(async (ctx) => …)`.
