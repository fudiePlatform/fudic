# FUD0421 — Route top level out of order
**error** · SDD-21

A route's top level has a fixed order — layout link, component links, `@code`, one `<head>`, markup — and its `@section`s live at that top level too.
**Fix:** reorder as `<link rel="layout">` → `<link rel="component">` → `@code` → `<head>` → markup, and move any nested `@section` to the top level.
