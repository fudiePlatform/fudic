# FUD0911 — The view mutates an object
**retired** · SDD-61

It was raised when the view called a method that writes — `sort`, `push`, `splice`, `set`, `add`, `Object.assign` and their kin. Since SDD-61 the view calls nothing but a reactive read and the four collection operations, so every one of those calls is already off the list.
**Replaced by:** `FUD1140`, on the callee.
