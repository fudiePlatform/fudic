# FUD1070 — Name with the wrong shape
**error** · SDD-60

Each class of `.fudapi` name has its shape: rules, middlewares, patterns and error codes are kebab-case (`nif-unique`, `nifUnique` in TS); functions, fields, arguments and forms are identifiers; types and enums are PascalCase.
**Fix:** rename it in the shape the message names.
