# FUD1546 — A placeholder that is not one
**error**

A `.headers` file fixes a nonce by hand (`'nonce-abc123'`), names a `{placeholder}` that does not exist, or writes `{nonce}` somewhere it is not filled: outside `'nonce-{nonce}'` of the CSP, or outside `page.headers`. A nonce is new for every response or it protects nothing.
**Fix:** write `'nonce-{nonce}'` in the CSP of `page.headers`, and nothing else between braces.
