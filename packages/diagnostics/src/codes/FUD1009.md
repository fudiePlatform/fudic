# FUD1009 — Server function shadowed in the browser
**error** · SDD-56

In the `@client` and the event expressions, the name of each server function of the file is the function that calls it.
A `@client` or neutral declaration with the same name would hide it, and every call would reach the wrong one.
**Fix:** rename one of them: `const saving = signal(false)` next to `export const save = put()…`.
