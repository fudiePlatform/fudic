# FUD1409 — Already a fudic project
**error**

`fudic_new` creates the project in the folder the MCP server was started in, and that folder has a `fudic.json` already, in it or above it. Creating another one there would write over the project that is there.
**Fix:** use `fudic_generate` to add to the project that exists, or start the server in an empty folder to create a new one.
