# FUD1581 — The error page links no layout
**error**

The project's `_error.fud` (`src/routes/_error.fud` of an app, `src/_error.fud` of a library) has neither a doctype nor a `<link rel="layout">`. An error page is a page, and every page links a layout.
Until it does, it is not compiled as the error page and the app renders errors with the minimal built-in page.
**Fix:** link the app's layout on its first line, or rewrite it with `fudic g error-page --force`.
