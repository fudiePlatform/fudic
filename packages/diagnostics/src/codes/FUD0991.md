# FUD0991 — Malformed props spread
**error** · SDD-07

`...item` hands a component one prop per key it declares, read from `item`. What follows the `...` is the object itself: a name or a property path such as `...row.data`, and nothing else.
The attribute takes no value: `...item="x"` has nothing to mean.
**Fix:** `<app-card ...item>`, or `<app-card ...row.data>`.
