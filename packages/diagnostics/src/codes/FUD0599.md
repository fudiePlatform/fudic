# FUD0599 — Marker with content or a dynamic id
**error** · BUG-41

The runtime writes the marker's content, so anything inside it would be overwritten; and `aria-describedby` has to name its `id`, which the compiler can only do when the `id` is static.
**Fix:** leave the marker empty and, if it has an `id`, write it as plain text: `<span id="title-error" error="@f.title"></span>`.
