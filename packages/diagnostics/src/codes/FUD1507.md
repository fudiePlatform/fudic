# FUD1507 — Not an argument of that function
**error**

`sent <fn> <field> <value>` reads one argument of the last call to the function, and the field names it: `user`, or a path into it such as `docs.0`. Its first segment has to be one of the arguments the function declares.
**Fix:** write the name of an argument of the function, as its `.fudapi` declares it.
