# FUD1078 — Contract and extensions in one file
**error** · SDD-60

A `.fudapi` is either a contract (`load`, `paths`, `layout`, functions, `chain`, `form`, `type`, `enum`, `messages`) or a file of extensions (`rule`, `middleware`, `pattern`, and the `type`/`enum` they use). Its first declaration decides which; this one is of the other kind.
**Fix:** move the declaration to a file of its kind; extensions are visible to the whole project without imports.
