# FUD1509 — A reference that does not parse
**error**

A reference is one or more steps joined by `>`, each a tag or `role:<role>`, with an optional name: `/"Delete"` for the exact accessible name, `/~"Luis"` for a name that contains the text. Each step searches inside the one before it. A `>` with no step on one side, or a `~` with no text, says nothing to search for.
**Fix:** write the missing step or the text, or remove the `>` or the `~`.
