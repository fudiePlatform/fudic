# FUD0804 — `fudic.runtime` directory missing
**error** · SDD-45

A package declares `fudic.runtime` in its `package.json`, and the directory it names does not exist or holds no piece. This build links those pieces by URL instead of bundling them, so pages would fetch files nobody wrote.
**Fix:** run the publishing package's own build, or remove the `fudic.runtime` declaration.
