# FUD1074 — Bad `load` option
**error** · SDD-60

The `load` line is the route's strategy: `load [ssg|ssr|sw] [ttl <dur>] [<policy>] [page <never|persist> [<dur>]]`, where a duration is a number and `s`, `m`, `h` or `d`, and the policy is `cache-first`, `network-first`, `stale-while-revalidate` or `network-only`.
**Fix:** write the option as the message expects: `load sw ttl 5m cache-first`.
