# FUD0894 — `@render` argument without `@`
**error** · SDD-48

A `@render` argument is written the way a prop is: a literal goes bare, and anything that reads the scope goes behind `@`. This is the SDD-48 rule that was numbered `FUD0444` before.
**Fix:** `@render card(@post.title, "New", 3)`, not `@render card(post.title, …)`.
