# FUD1504 — The route needs its params
**error**

A page with params in its path has no URL of its own: `/blog/[slug]` is opened as `/blog/hola`, never as `/blog/[slug]`. Each criterion says which one.
**Fix:** add `path <value>` with a value of the fixture's `paths`, or `url <url>` with the whole URL, in `given`.
