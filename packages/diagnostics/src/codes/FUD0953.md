# FUD0953 — No fixture file
**error**

A fixture line reads its names from the `.fixture.ts` of what the spec opens: `<tag>.fixture.ts` beside a component, `<route>.fixture.ts` beside a page, `<name>.fixture.ts` beside a flow. There is none.
**Fix:** write the fixture file, with an `export default { … } satisfies` the type it fills.
