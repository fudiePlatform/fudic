# FUD1007 — `.client` half in the `@server`
**error** · SDD-56

The `@server` never reaches the browser, so a middleware declared there is server-only. Its `.client` half would silently never run.
A middleware with both halves lives in a module that both sides import.
**Fix:** move it to `src/middlewares/auth.ts` and `import { auth } from '../middlewares/auth'` in the `@server`.
