# FUD0803 — Inline runtime without a nonce
**error** · SDD-45

A layout asks to carry the runtime inside the document (`fudic:runtime?inline`), and the document's Content-Security-Policy declares no `'nonce-{nonce}'`. A strict `script-src` drops the inline module: the page renders and nothing hydrates.
**Fix:** declare `'nonce-{nonce}'` in the document policy, or link the runtime instead of inlining it.
