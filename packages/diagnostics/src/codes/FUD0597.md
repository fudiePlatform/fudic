# FUD0597 — Marker with no bound control
**error** · BUG-41

An `error=` or `summary=` marker describes an element beside it that binds the same node with `control`. No element of its block does, so `aria-describedby` would point from nothing.
**Fix:** put the marker in the same block as the control it describes: `<input control="@f.title"> <span error="@f.title"></span>`.
