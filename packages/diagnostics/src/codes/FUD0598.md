# FUD0598 — Marker repeated or inside a loop
**error** · BUG-41

A node speaks through one marker element, whose id `aria-describedby` names. A marker inside a loop gives every row the same id, and a second marker for the same node gives it two.
**Fix:** keep one `error=`/`summary=` marker per node, outside any `@foreach`/`@for`/`@while`.
