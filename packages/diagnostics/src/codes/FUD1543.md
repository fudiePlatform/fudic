# FUD1543 — A value the header does not accept
**error**

The value does not have the form its header requires: a CSP source written wrong, a `Cache-Control` directive without its number, a `Cross-Origin-Opener-Policy` or `Referrer-Policy` that does not exist. Or the value is empty outside `assets.headers`, where empty means "do not send".
**Fix:** write a value the header accepts (the message names them), or remove the line.
