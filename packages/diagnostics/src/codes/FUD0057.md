# FUD0057 — Unknown character reference
**error**

The text contains `&name;` and fudic does not know `name`. fudic only reads the five references of XML (`&lt;`, `&gt;`, `&amp;`, `&quot;`, `&apos;`) and the numeric ones (`&#160;`, `&#xA0;`); the rest of the HTML table, `&nbsp;` and `&hellip;` included, is not read.
**Fix:** type the character itself (`…`), or write it by its number (`&#160;` for a non-breaking space), or write a literal ampersand as `&amp;`.
