# FUD0992 — Spread on the component's own host or shadow template
**error** · SDD-54, SDD-55

`...item` hands props to a component (`<app-card ...item>`) or writes attributes on a native element (`<input ...resto>`). The host wrapper declares the component and the `<template shadowrootmode>` becomes its shadow root: neither is an element the view writes on, so there is nothing to spread into.
**Fix:** move the spread to the component or the native element inside the template that should receive it.
