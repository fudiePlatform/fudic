# FUD0992 — Props spread on an element that is not a component
**error** · SDD-12

`...item` expands against the props the child component declares in `props<T>()`. A native element, or a tag no `<link rel="component">` resolves, declares none, so there is nothing to expand into.
**Fix:** spread on a component (`<app-card ...item>`), or write the attributes one by one.
