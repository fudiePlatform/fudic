# FUD0456 — Unusable stylesheet name
**error** · BUG-50

`fudic g style` names the sheet in `globalStyles`, and that name is how pages adopt it: letters, digits and `_`, starting with a letter. No hyphen, so a sheet is never mistaken for a component's own. The name may also be one the project already uses. Nothing is written.
**Fix:** pick another name, e.g. `fudic g style theme`.
