# FUD1068 — Malformed literal
**error** · SDD-60

An initial value (`= ""`), a rule argument (`min-length 3`), a status (`fails reserved 409`) or a function route (`get pizza /:id`) has a fixed shape. This one does not read as what its place expects.
**Fix:** write it in the shape the message names: a quoted string, a number, `true`/`false`, a three-digit status or a route like `/:id/lines/:line`.
