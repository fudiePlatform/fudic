# FUD1005 — `form:=` without a server function
**error** · SDD-56

`form:=@save` calls `save(form)` when the form is valid, so `save` has to be a server function exported from the `@server` of the same file.
A function of the `@client` is not one: it is called with `@submit`.
**Fix:** `export const save = put().form(userForm).handle(…)` in the `@server`, then `<form control=@userForm form:=@save>`.
