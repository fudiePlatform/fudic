# FUD1005 — `form:=` without a server function
**error**

`form:=@save` calls `save(form)` when the form is valid, so `save` has to be a server function: one declared in a `.fudapi` the file links with `<link rel="server">`.
A function of the `@code` is not one: it is called with `@submit`.
**Fix:** declare it in the linked `.fudapi` (`put save` with a `form userForm` line), then `<form control=@userForm form:=@save>`.
