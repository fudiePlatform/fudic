# FUD1500 — The page does not exist
**error**

`page <route>` names a page by its path on disk, from the routes folder and without extension: `page /` is `index.fud`, `page /blog/[slug]` is `blog/[slug].fud`. No page answers the one written, so the criteria have nothing to open.
**Fix:** write the path of an existing page, or create the page first.
