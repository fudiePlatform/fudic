# FUD0941 — Unreadable term `meta`
**error** · SDD-52

The validator reads `meta` without running the module, so it must be `export const meta = { … }` with `name`, `block` and `params` written as literals, and the file must parse.
**Fix:** write `meta` as an object literal, with string literals for `name`, `block` and every parameter's `name` and `type`.
