# FUD0910 — Reflective access in the view
**error**

A member named `constructor`, `__proto__` or `prototype` reaches `Function` and the prototypes, which no data field means and no other backend has.
**Fix:** read a field the data has instead of the machinery, `@item.kind` and not `@item.constructor.name`; moving the read to `@code` does not help, because the server evaluates what the view reads from it.
