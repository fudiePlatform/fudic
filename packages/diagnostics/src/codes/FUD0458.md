# FUD0458 — Unusable snippet or snippet file name
**error** · BUG-50

`fudic g snippet <file> <name>` writes `@snippet <name>()` into `src/snippets/<file>.fud`. The snippet's name is a function name in a `@render` header, so it takes letters, digits and `_` and no hyphen; the file's name is kebab-case. Nothing is written.
**Fix:** e.g. `fudic g snippet ui productCard`.
