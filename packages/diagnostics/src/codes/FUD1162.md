# FUD1162 — JSX in the markup
**warning**

Braces in the markup are text, so a `.map(…)` or a `&&` inside them is printed on the page as code instead of rendering a list or a condition. Code meant to be shown, as in a tutorial, goes inside `<code>` or `<pre>`, where this is not reported.
**Fix:** write the loop or the condition with `@foreach (const item of items) key (item.id) { … }` or `@if (open) { … }`.
