# FUD0974 — Signal value not literal
**error** · SDD-32

A `Signal` prop is created by a host component the workbench writes, with the fixture's initial value written as a literal. A function, a date, a `Map` or `undefined` does not come back the same from `JSON.stringify`, so that criterion ends in error.
**Fix:** give the signal a plain JSON value (number, string, boolean, null, array or object).
