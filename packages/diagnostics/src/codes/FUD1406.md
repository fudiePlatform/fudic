# FUD1406 — cloudflared is not installed
**warning**

A chat reaches the MCP server from the internet, not from this machine, so it needs a public URL. `--tunnel` opens one with `cloudflared`, and `cloudflared` is not on the PATH. The server keeps running on its local URL.
**Fix:** install `cloudflared` (`winget install Cloudflare.cloudflared`, `brew install cloudflared`, or the package from Cloudflare's site) and start again, or point a tunnel of your own at the local port.
