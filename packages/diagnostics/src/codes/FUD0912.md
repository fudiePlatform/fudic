# FUD0912 — `now()` outside a signal's initializer
**error** · SDD-61

The server evaluates `signal(now())` once per render and sends the value in `fud-state`, so the browser that hydrates reads the same instant. Anywhere else (the view, a `computed`, a `const`, a store evaluated once per process) each side would read its own clock.
**Fix:** declare `const ahora = signal(now())` in `@code` and read `ahora()`.
