# FUD0430 — Layout exports `load`
**error** · SDD-21 · SDD-60

A layout does not load data of its own: it receives the route's data read-only, so a static route can never be turned dynamic by its layout. A layout links no `.fudapi` (`FUD1112`), and an `export function load` in its `@code` is this error.
**Fix:** declare `load` in the route's `.fudapi`, and read what the layout needs from the data it receives.
