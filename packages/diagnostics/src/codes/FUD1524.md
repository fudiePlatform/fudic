# FUD1524 — A feature newer than the project's Baseline
**warning**

The HTML, CSS or TypeScript uses something of the browser that is not in every core browser as far back as the project's `baseline` in `fudic.json` reaches (`widely` when it says nothing). In an older browser it is ignored or throws.
**Fix:** guard it — CSS inside `@supports (…)`, JS behind `'name' in object` or `typeof X === 'function'` — or allow the feature in `fudic.json` (`"baseline": { "target": "widely", "allow": ["popover"] }`), or raise the `target`.
