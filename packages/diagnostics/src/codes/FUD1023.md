# FUD1023 — Unreadable catalog
**error** · SDD-58

A `src/locales/<locale>.json` is not valid JSON, or is not an object of contexts holding objects of entries with `source`, `where` and `at`. The build falls back to the original text for every message of that locale.
**Fix:** correct the file where the message points, or delete it and run `fudic translate` again.
