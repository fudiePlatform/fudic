# FUD1502 — A path the fixture does not list
**error**

`path <value>` opens the page at the URL its pattern gives with that value, and the value is one of the `paths` of the page's fixture. A value outside the list is a URL the fixture does not stand for.
**Fix:** write one of the listed values, add it to the fixture's `paths`, or write the whole URL with `url`.
