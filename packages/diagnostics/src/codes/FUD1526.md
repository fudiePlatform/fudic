# FUD1526 — A library uses features the app does not accept
**warning**

A library this app uses writes HTML, CSS or TypeScript newer than the app's `baseline`, unguarded. The library promised its own level; the app asks for older browsers, where those parts are ignored or throw.
**Fix:** allow those features in the app's `fudic.json` (`"allow": [...]`) if they are acceptable, or raise the app's `target`, or ask the library to guard them.
