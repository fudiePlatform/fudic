# FUD1324 — `later` outside the fields of `load`
**error** · SDD-70

`later` says that `load` returns a field as a promise, so the page can be sent before it resolves. A `type`, a `form`, the arguments or the return of a function and the `adds` of a middleware are whole values: nothing renders them part by part.
**Fix:** only a field of `load` can arrive later; resolve the value before returning it.
