# FUD1001 — Server function without `.handle`
**error** · SDD-56

A verb opens a server function and `.handle(…)` closes it; until then it is only a builder, and there is nothing to call.
An exported builder is almost always a forgotten `.handle`; a base meant to be reused is a plain `const`.
**Fix:** `export const save = put().use(auth).handle(async (ctx) => { … })`.
