# FUD1582 — No layout to link
**error**

`fudic g page`, `fudic g error-page` or `fudic g showcase` found no layout for the file it would write. Every page links a layout, so the CLI writes nothing rather than a page without one.
**Fix:** create the layout with `fudic g layout _layout` (add `--project <name>` in a workspace), or name one with `--layout <href>`.
