# FUD0366 — Public file reached by a relative path
**error** · BUG-40

A relative path hands the URL to the build, which hashes and publishes the file; a root-absolute one keeps the name the file has under `public/`. Reaching into `public/` with `../../public/logo.svg` asks for both, and publishes a second, hashed copy of a file already served under its own name.
**Fix:** write the URL: `/logo.svg`.
