# FUD1145 — A collection operation in a form that does not port
**error** · SDD-61

`filter`, `map`, `reduce` and `toSorted` take one arrow with an expression body and plain parameters (`x`, `(x, i)`, `(acc, x)`, `(a, b)`), and `reduce` takes its initial value. A block body, a function name, an extra parameter or argument, or a `reduce` without its initial value has no lowering.
**Fix:** pass a one-expression arrow with plain parameters; give `reduce` its initial value.
