# FUD0433 — Bad layout directive argument
**error** · SDD-21

A layout directive takes a fixed shape: `@section` and `@RenderSection` take a bare identifier as name, and the named arguments are a closed set per directive, each once — `slot: "x"` (a string) and `required: true|false`.
**Fix:** `@RenderSection(sidebar, required: true, slot: "aside")`, `@RenderBody(slot: "main")`, `@RenderHead()`, `@section sidebar { … }`.
