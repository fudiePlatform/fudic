# FUD1440 — A piece of the guide is not adopted
**warning**

The page gets the whole style guide, but a component only gets the pieces it names in `shadowrootadoptedstylesheets`. This element is styled by a piece the component does not name, so inside the component it falls back to the browser's look.
**Fix:** add the piece's name to the attribute: `shadowrootadoptedstylesheets="button"`. The quick fix does it.
