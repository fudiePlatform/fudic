# FUD1555 — Trusted Types will block this assignment
**warning**

`page.headers` has `require-trusted-types-for 'script'`, and browser code gives a plain `string` to a sink that takes HTML, script or a script URL (`innerHTML`, `insertAdjacentHTML`, `eval`, …). The browser throws there.
**Fix:** pass a `TrustedHTML`/`TrustedScript`/`TrustedScriptURL` from a policy whose name is in `trusted-types`, or use `textContent` when it is text.
