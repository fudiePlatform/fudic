# FUD1026 — Translating an app in a single language
**error** · SDD-58

`fudic translate` writes one catalog per language besides the one the code is written in, and this app has only that one: no `locales` in `fudic.json` is `en`, and `["es"]` is Spanish alone. A single language has no catalog, and the build compiles it as written.
**Fix:** list the other languages, e.g. `"locales": ["es", "en"]`, with the language the code is written in first.
