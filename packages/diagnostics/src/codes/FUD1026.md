# FUD1026 — Translating an app without locales
**error** · SDD-58

`fudic translate` writes one catalog per language, and the app's `fudic.json` names none. Without `locales` the app is in a single language: nothing is extracted and the build compiles it as written.
**Fix:** add `"locales": ["es", "en"]` to `fudic.json`, with the language the code is written in first.
