# FUD0423 — Layout without `@RenderBody()`
**error** · SDD-21

A layout is the shell a route is rendered into, and `@RenderBody()` marks where the route goes. A file without it — or one a `<link rel="layout">` points at that lacks it — has nowhere to put the route.
**Fix:** add `@RenderBody()` inside the layout's `<body>`.
