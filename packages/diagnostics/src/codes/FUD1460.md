# FUD1460 — `debounce` in a rule that is not remote
**error**

`debounce` is the wait between the last keystroke and the question the browser sends to the server. Only a `runs remote` rule is asked while typing; a `both` rule runs in place and a `server` rule only on submit.
**Fix:** write `runs remote` in the rule, or drop the `debounce` line.
