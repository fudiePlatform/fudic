# FUD0702 — The route does not resolve a required layout prop
**error**

The layout declares a prop with no default and not optional, and the route resolves no `layout`, so the layout would render with it undefined.
**Fix:** declare `layout` in the route's `.fudapi`, link it with `<link rel="server" href="./index.fudapi">` and return the prop from its handler (`layout.handle(() => ({ section: "Home" }))`), or give it a default in the layout.
