# FUD0702 — The route does not resolve a required layout prop
**error** · SDD-40

The layout declares a prop with no default and not optional, and the route's `layout(ctx, data)` does not return it, so the layout would render with it undefined.
**Fix:** return the prop from `export function layout(ctx, data)` in the route's `@server`, or give it a default in the layout.
