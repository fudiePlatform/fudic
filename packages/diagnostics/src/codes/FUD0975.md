# FUD0975 — No browser to run the criteria
**error** · SDD-32 · BUG-48

The workbench runs the criteria in a browser without a window. With `--browser auto` (the default) it tries the system Chrome, then the system Edge, then the Chromium that Playwright downloads; with a name it tries only that one. None could be started.
**Fix:** install Chrome or Edge, or run the command in the message (`npx playwright-core install chromium`, or the browser you asked for).
