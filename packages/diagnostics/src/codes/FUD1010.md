# FUD1010 — `_error.fud` with its own data
**error** · SDD-56

`_error.fud` is the error page: its `data` is `{ status, title, detail }`, given by whatever failed, and its only URL is `/_fudic/error/:status`.
It has no `load` to run, no `paths` to prerender and no server functions to call.
**Fix:** remove the declaration and read `@data.status`, `@data.title` and `@data.detail`.
