# FUD1552 — A long cache on a file without a hash
**warning**

A rule of `assets.headers` puts `immutable`, or a `max-age` of a day or more, on a file of the build whose name has no hash (a favicon, a `public/` file). When it changes, the browser keeps the old one.
**Fix:** narrow the rule to the hashed files (`/assets/**`), or give the others their own block with `no-cache`.
