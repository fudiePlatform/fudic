# FUD0720 — `class:` on the component's own tag
**error** · BUG-32

The classes a file declares live in its `<style>`, inside the shadow; a class on the host tag is resolved against the page around it, which this file cannot see. The binding would style nothing.
**Fix:** put the `class:` on the element inside the template where it applies, or expose the state as an attribute on the host.
