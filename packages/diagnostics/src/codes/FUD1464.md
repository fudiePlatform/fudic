# FUD1464 — `$value` from marks of different types
**error**

A delegated `@change=@f(p, $value)` reads the value of the marked element that fired it. When a checkbox and a number input are both marked `delegate:p`, `$value` would be a `boolean` or a `number | null` depending on the row.
**Fix:** say which events each marker serves (`delegate:p="click"` on the one that should not reach this handler).
