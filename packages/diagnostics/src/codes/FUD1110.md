# FUD1110 — `@server` or `@client` in a `@code`
**error** · SDD-60

The `@code` of a `.fud` is browser code, all of it: the server evaluates only what the markup needs. A `@server` region moves to a sibling `.fudapi` (its `load`, functions and forms), linked with `<link rel="server" href="./page.fudapi">`, and its handlers to `src/server`. A `@client` region simply loses its wrapper. The content of the region is still read, so nothing else is reported because of it.
**Fix:** move `@server` to the `.fudapi` and `src/server`; unwrap `@client`.
