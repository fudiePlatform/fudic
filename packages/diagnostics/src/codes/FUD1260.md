# FUD1260 — Rule not for an argument
**error**

An argument of a function takes the eight built-in rules of `@fudic/forms`: `required`, `min`, `max`, `min-length`, `max-length`, `pattern`, `max-size` and `accept`. A rule of the project is written for a form: it receives the form, and an argument has none.
**Fix:** check it in the handler, or use one of the built-in rules: `max-length 80`.
