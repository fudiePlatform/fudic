# FUD0667 — `delegate:` marker with a wrong value
**error** · SDD-37, SDD-72

A `delegate:` marker takes no value, or a literal text with the events it serves, separated by spaces. An expression (`delegate:day=@d`) or an empty text is neither.
**Fix:** `<li delegate:day>` to serve every handler, or `<li delegate:day="click">` to serve only `@click`.
