# FUD1075 — Bad status or compression
**error** · SDD-60

A `fails` declares a rejection, so its status is an error one, `400`–`599`. A `compress` names `gzip`, `deflate` or `deflate-raw` with an optional minimum size in bytes, or is `compress off`.
**Fix:** `fails reserved 409 "…"`, `compress gzip 200`.
