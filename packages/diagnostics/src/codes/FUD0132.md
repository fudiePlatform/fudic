# FUD0132 — Razor inside `<style>`
**error** · SDD-49

The body of a `<style>` is plain CSS: an `@` there is only valid in front of a CSS at-rule (`@media`, `@-webkit-…`), never as an expression, construct or Razor comment.
**Fix:** move what changes to the markup: `style="width: @(w)px"`, `style:width="@w"` or `class:active="@on"`.
