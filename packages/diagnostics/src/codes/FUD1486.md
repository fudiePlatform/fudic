# FUD1486 — A file input bound to something that is not a file
**error**

An `<input type="file">` gives a `File` (or a list of them), and only a `file` or `file[]` field can hold it; the other way round, no other control can choose a file.
**Fix:** bind the file input to a `file` field, or use `type="file"` for the file field.
