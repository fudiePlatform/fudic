# FUD1462 — `$value` with no control
**error**

`$value` reads the value of an `<input>`, `<textarea>` or `<select>`. A `<div>`, a `<button>`, a component tag, a `bus:` binding or `@fudic:result`/`@fudic:error` have no value to read.
**Fix:** move the handler to the control, or pass `$event` and read what you need from it.
