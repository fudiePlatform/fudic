# FUD1153 — A type that does not port
**error** · SDD-61

The view reads strings, numbers, booleans, dates, unions of literals, lists, maps and named types from the `.fudapi` or a component's props. An anonymous nested object, a tuple, a class, `any`, a text index on an object or a destructured `map` has no type in the other backends.
**Fix:** declare the type in the `.fudapi`.
