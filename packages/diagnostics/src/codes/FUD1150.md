# FUD1150 — A declaration the server cannot evaluate
**error** · SDD-61

What the view reads, transitively, is evaluated on the server in the backend's language. A function used as a value, a class, a `let` with no initializer or a name from a package outside fudic's catalogue has no lowering.
**Fix:** use `signal`, `computed` or a `const` the view can read.
