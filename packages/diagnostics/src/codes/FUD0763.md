# FUD0763 — Link into a package that is not a library
**error** · SDD-43

The href resolves to a `.fud` inside a package whose `fudic.json` does not say `{ "kind": "lib" }`. Reaching into it is a coupling nobody declared, and it breaks the day that package reorganizes its folders.
**Fix:** link a published library instead, or declare the package `"kind": "lib"` if it is meant to be consumed.
