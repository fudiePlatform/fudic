# FUD0976 — Nothing to run
**error** · SDD-32 · BUG-48

`fudic-workbench run` runs the criteria of every `.fudspec` it finds: under the project when it gets no paths, or in the files and folders it was given. It found none. A run with nothing in it fails, so that a CI that lost its specs does not pass in green.
**Fix:** write a `.fudspec` next to a component, or point `run` at the folder that has them.
