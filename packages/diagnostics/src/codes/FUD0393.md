# FUD0393 — `strategy()` is not a literal
**retired**

It warned on a `strategy()` call whose argument the build could not read without running it.
The `.fud` no longer carries a server: the strategy is the `load` line of the route's `.fudapi`, read by its parser. The number is not reused.
