# FUD1466 — Named handler without a row
**error**

`@click.borrar` lets two handlers of the same event live on one parent, each served by its own marks. Without a delegated row to read there is no mark to serve it, and it would just be a `@click` with another name.
**Fix:** read the row in the handler (`@click.borrar=@borrar(p)`) and mark the element `delegate:p="click.borrar"`, or write a plain `@click`.
