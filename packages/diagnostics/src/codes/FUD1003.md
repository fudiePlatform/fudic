# FUD1003 — Server function with a reserved name
**retired**

It reported a server function named `paths`, `layout` or `http`.
The `.fud` no longer carries a server: `paths` and `layout` are keywords of a `.fudapi`, and a function cannot take their name. The number is not reused.
**Replaced by:** nothing: in a `.fudapi`, `paths` and `layout` are declarations of their own.
