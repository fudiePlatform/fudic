# FUD1094 — Initial value of the wrong type
**error** · SDD-60

The value after `=` is what the field holds before the user touches it, so it must be of its type: a string for `str`, `date` and `uuid`, `true`/`false` for `bool`, a number in the range of its width, `[]` for a list.
**Fix:** write a value of the field's type, or drop the `= …` to take the default.
