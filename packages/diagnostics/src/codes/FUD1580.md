# FUD1580 — A whole document is a layout
**error**

A `.fud` that starts with `<!DOCTYPE html>` is always a layout, and this one has no hole (`@RenderBody()`, `@RenderHead()`, `@RenderSection()`). There is no page without a layout.
If it is a page: drop the doctype, `<html>` and `<body>`, and link the app's layout with `<link rel="layout" href="…">` on the first line.
If it is a layout: add `@RenderBody()` inside its `<body>`.
