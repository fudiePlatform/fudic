# FUD0802 — Output holds a runtime piece with other bytes
**warning** · SDD-45

Applications sharing an origin write the same published piece with the same bytes, because the framework built it. Different bytes mean one version of the package was published twice with two contents, and whichever application deploys last decides what every page runs. The running build is not the one at fault, so it goes on.
**Fix:** republish the package under a new version, and redeploy the applications of the origin.
