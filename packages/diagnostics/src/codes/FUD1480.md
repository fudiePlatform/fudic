# FUD1480 — A file cannot travel in a URL
**error**

The arguments of a `get`, a route parameter and a query parameter are written in the URL, and a file's bytes do not fit there. A file goes in the body of a call, as a part of `multipart/form-data`.
**Fix:** make the function a `post` (or `put`, `patch`, `delete`) and keep the file as a body argument.
