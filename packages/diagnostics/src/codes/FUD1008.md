# FUD1008 — Component server function reading instance state
**error** · SDD-56

The rest of a component's `@server` runs inside each render; a server function runs on a call, which is not a render, so those variables do not exist for it.
It can read what is module-wide: the imports of the `@server` and the other server functions.
**Fix:** pass the value in the arguments or the form, or move it to a module and import it.
