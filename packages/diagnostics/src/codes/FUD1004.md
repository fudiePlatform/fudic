# FUD1004 — `http` that is not a chain
**error** · SDD-56

`export const http` is the middle level of the chain: what every server function of the file, `load` included, inherits after the global one.
It is a `chain()`, not a function: it has no verb and no `.handle`.
**Fix:** `export const http = chain().skip('*').use(apiKey)`.
