# FUD0593 — Misplaced `formassociated`
**error** · SDD-34

`formassociated` decides what the component's class is, so it only means something on the component's own root `<template shadowrootmode>`. On a nested template, or in a page, there is no class for it to change.
**Fix:** move it to the root template: `<app-input><template shadowrootmode="open" formassociated>`.
