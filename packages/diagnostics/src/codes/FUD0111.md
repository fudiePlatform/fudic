# FUD0111 — `@server`/`@client` take no parameter
**retired**

It reported a parenthesized argument after `@server` or `@client`.
The `.fud` no longer carries a server: a `@code` has no regions, so a region has nothing to accept. The number is not reused.
**Replaced by:** FUD1110 (`@server` or `@client` in a `@code`).
