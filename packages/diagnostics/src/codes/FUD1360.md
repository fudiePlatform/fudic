# FUD1360 — `fails` under `load`
**error**

A function names its failures with `fails` so the page that called it can paint their text in its own language. A `load` has no caller to paint anything: when it fails, the page cannot be rendered and the user goes to `error-pages`, by status.
**Fix:** remove the line and throw from the handler of `load`: `throw notFound()`.
