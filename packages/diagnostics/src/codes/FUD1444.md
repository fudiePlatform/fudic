# FUD1444 — The project already has a style guide
**error**

`fudic g guide` writes a style guide into a standalone app and names it in the `guide` of its `fudic.json`. This one already names one, and a project has a single guide: a second would leave the first unused.
**Fix:** edit the guide you have, or remove `guide` from `fudic.json` to start again.
