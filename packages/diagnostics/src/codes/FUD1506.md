# FUD1506 — A function the page cannot call
**error**

`called` and `sent` read the log of the calls a criterion made. A page can call the functions of its route and of the components it uses, and its remote rules; a flow, those of the whole project. A function outside that reach never shows in the log, so the line could only fail.
**Fix:** write the name of a function in reach, as its `.fudapi` declares it.
