# FUD0823 — `@code` in a snippet
**error** · SDD-29

A snippet is markup reuse, not a component: it has no state of its own, and every value in its markup arrives as an argument. A `@code` inside a `@snippet`, or at the top of a file of snippets, would never run.
**Fix:** move the code to the component or route that renders the snippet, and pass the values in: `@render card(@item)`.
