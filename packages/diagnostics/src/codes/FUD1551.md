# FUD1551 — The Service Worker downloads this file twice
**warning**

A rule of `assets.headers` puts `no-cache` or `no-store` on a file the Service Worker precaches (the `shell`, or a `cache-first` resource of `sw.json`). The page downloads it, and the worker downloads it again instead of taking it from the HTTP cache.
**Fix:** give those files a cache (`max-age`, `immutable` when the name has a hash), or stop precaching them.
