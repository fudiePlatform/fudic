# FUD0098 — Expression attribute name outside `bus:`
**error**

Only a `bus:` binding may compute its name with `( … )`; any other name followed by a parenthesis has no meaning. A `(` glued to a name is read as part of it, so `<x ...rest()>` and `<x @click(go)>` land here instead of becoming silent attributes called `(` and `)`.
**Fix:** use `bus:(EVENTS.cart)="@h"`; write a spread as a name or a path (`...rest`) and an event value as `@click=@go`.
