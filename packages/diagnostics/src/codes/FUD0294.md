# FUD0294 — Reserved `data-fud-*` attribute
**error** · SDD-15

The compiler writes its own markers (`data-fud-id`, `data-fud-adopt`, …) in the `data-fud-` namespace, and a hand-written one breaks hydration silently. `data-fud-space` is the one name meant for authors.
**Fix:** rename the attribute to a `data-` name of your own: `data-id` instead of `data-fud-id`.
