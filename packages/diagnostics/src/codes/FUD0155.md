# FUD0155 — Component top level out of order
**error** · SDD-10

A component's top level has a fixed order — links, then `@code`, then one `<head>`, then the host element — and something arrives out of phase or repeats.
**Fix:** reorder the file as `<link …>` → `@code { … }` → `<head>…</head>` → `<my-tag>…</my-tag>`.
