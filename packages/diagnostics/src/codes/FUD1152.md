# FUD1152 — An operator on a type it does not port for
**error** · SDD-61

Arithmetic takes numbers, `+` joins text with text or numbers, `<` compares two numbers, two strings or two dates, `===` compares primitives, and a `toSorted` comparator returns a number. Anything else relies on JS's coercions.
**Fix:** convert the value in `load()`.
