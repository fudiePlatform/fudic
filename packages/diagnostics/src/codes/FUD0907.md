# FUD0907 — Name not available to the view
**error**

The view reads only what the file or the template declares and what the file's role provides. Its one global is `undefined`: `Math`, `JSON`, `Date`, `Intl`, `NaN` and the rest exist only in JS.
**Fix:** import or declare it in `@code` with a value that reads no JS global (`const pi = 3.14159`, not `Math.PI`, which the server evaluates too), or compute the value in `load()`.
