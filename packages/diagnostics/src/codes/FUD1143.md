# FUD1143 — A literal the view cannot hold
**error** · SDD-61

An object or array literal has no named type the other backend languages could build, a `bigint` has no common width, and a string with a lone surrogate is not valid text outside JS. The holes object of `t()` is the one exception.
**Fix:** declare the data in `@code` with a `.fudapi` type, or receive it from `load()`.
