# FUD1400 — Outside the project
**error**

The MCP server only reads and writes inside the project it was started in. A path that climbs out of it (`..`, an absolute path elsewhere, a link that points outside) or that enters `.git`, `node_modules` or the generated `.fudic` folder is refused, and nothing is read or written.
**Fix:** use a path relative to the project root, such as `src/components/app-card/app-card.fud`.
