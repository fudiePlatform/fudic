# FUD0200 — Signal prop fed a non-signal
**error** · BUG-24

The child declares this prop as a `Signal<T>`: it receives the cell itself, so the value has to be the bare name of a `signal(…)` or `computed(…)` of this component.
**Fix:** pass the reactive by name: `.count="@count"`, not `.count="@count()"` or an expression.
