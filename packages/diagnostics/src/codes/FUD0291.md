# FUD0291 — Unsuitable event handler
**error** · SDD-15

The value of an `@event` or `bus:` binding must be something that can be subscribed: a reference, a call, a lambda or a function. Any other expression has no listener to hand to the DOM.
**Fix:** name the handler or wrap it: `@click="@save"`, `@click="@save(item.id)"`, `@click="@(() => count.set(0))"`.
