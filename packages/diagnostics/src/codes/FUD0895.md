# FUD0895 — `@` argument is not a path
**error**

After a bare `@` a `@render` argument is a name or a path (`@a.b`, `@count()`), and `@( … )` is that group alone; anything more is ambiguous. This rule was numbered `FUD0445` before.
**Fix:** wrap the whole expression: `@(a + b)` instead of `@a + b`.
