# FUD0452 — Base URL already taken
**error** · BUG-50

`fudic g app` was asked for a base URL that another app of the workspace already has. `fudic dev` and `fudic preview` serve every app on one port, each under its base, so two apps under one base would answer the same URLs. Nothing is written.
**Fix:** pick another one with `--base /<path>/`, or change the `base` in the other app's `vite.config.ts`.
