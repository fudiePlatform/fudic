# FUD1488 — Server options in fudic.json
**error**

`server` in `fudic.json` holds `trustProxy` (true or false) and `uploads` (`maxFileSize` and `maxArgs` as bytes or a size such as `"50mb"`, `maxFiles` as a whole number). Anything else is a typo that would leave a default in place without a word.
**Fix:** write the field with the shape the message names, or remove it to keep the default.
