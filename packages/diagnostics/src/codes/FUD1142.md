# FUD1142 — An operator that does not port
**error** · SDD-61

`==`, `!=`, `typeof`, `instanceof`, `in`, `void`, unary `+`, `~`, the bitwise operators and `**` depend on JS's coercions or have no single equivalent in the other backend languages.
**Fix:** use `===`, `!==`, `<`…; test presence with `=== null`.
