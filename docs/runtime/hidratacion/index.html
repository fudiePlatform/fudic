Página SSR — cero JS de componente hasta el primer clic

Abre DevTools → Network (filtro JS) y Console. Al cargar solo baja runtime.js. Al primer clic en un componente baja su components/<tag>.js (network-first, y el SW lo cachea). Recarga o vuelve a interactuar con otra instancia del mismo tag → el chunk sale de ServiceWorker/cache, no de red. Comprueba en consola: document.querySelectorAll(':not(:defined)') — los tags desaparecen de esa lista a medida que se hidratan.
